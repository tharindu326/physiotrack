    Guides¶

    Task-focused guides for every Physiotrack capability. Each predictor follows the same shape: pick a preset, call predict(frame) (or the instance directly), and read a Result that renders its own overlay via result.plot(). Weights are auto-downloaded from Hugging Face on first use and cached.

    One mental model, every task

    All image predictors — Detection, Pose, Segmentation, Face — return a Result. Depth returns a DepthResult. Learn the result object once and it transfers everywhere.

    • Detection

      Person, face, and VR object boxes with confidence and class labels.

      Detection guide

    • Pose Estimation (2D)

      COCO-17 and WholeBody-133 keypoints with auto person detection.

      Pose guide

    • 3D Pose & Canonicalization

      Lift 2D keypoints to 3D and canonicalize pose geometry.

      Pose 3D guide

    • Segmentation

      Person masks, VR-head parts, Sapiens body parts, and 19-class face parsing.

      Segmentation guide

    • Depth

      Monocular dense depth with Depth-Anything-V2 (Small / Base / Large).

      Depth guide

    • Face & Head Orientation

      Face detection, VR-face crops, and 6-DoF yaw/pitch/roll head pose.

      Face guide · Runnable examples · Validation

    • Tracking

      Persistent multi-object ids across frames from any detector.

      Tracking guide

    • Video Pipeline

      Orchestrate detection, pose, tracking, and overlays over whole videos.

      Video guide

    • Signals (rPPG · Motion · ROM)

      Heart rate from skin pixels, joint angles, and range-of-motion features.

      Signals guide
