# Bundled face-tracking media

`students_face_tracking.mp4` is a 10-second synthetic classroom scene (1280×720,
24 FPS) generated through Google Gemini on **August 13, 2026** and supplied by the
project contributor. The contributor confirms that the clip's people and scene
imagery was generated using **Nano Banana 2** (**Gemini 3.1 Flash Image**). Because
Nano Banana 2 is an image model, the separate video-animation model is recorded as
unknown rather than being inferred. The original filename was
`POV_scene_of_students_work_1.mp4`; the MP4 also carries a `Google` encoder tag.

The clip is intentionally small enough for a repository example. It has no
ground-truth face boxes or track identities, so it supports a qualitative API demo,
not an accuracy claim. All depicted people, faces, and personal traits are
computer-generated; no real living person is represented, and any resemblance is
coincidental. The contributor dedicates any copyright and related rights they hold in
the media file under **CC0 1.0 Universal**, while the repository's code and
documentation remain GPL-3.0-or-later. The supplied MP4 was copied without
transcoding, preserving its encoder metadata and any embedded SynthID, if present;
the watermark has not been independently verified here.
