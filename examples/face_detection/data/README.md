# Bundled face-detection media

The project contributor confirms that these four entirely synthetic scenes were
generated with Google Gemini using **Nano Banana 2** (**Gemini 3.1 Flash Image**) on
**August 13, 2026**:

| File | Scene tested | Original contributor filename |
| --- | --- | --- |
| `selfie/two_person_selfie.jpg` | two large, near-camera faces | `Gemini_Generated_Selfie_1.jpg` |
| `pov/exercise_class_pov.jpg` | occlusion and mixed face scale in a first-person scene | `Gemini_Generated_POV_1.jpg` |
| `crowd/outdoor_cafe_crowd.jpg` | many foreground and background faces | `Gemini_Generate_Crowd_1.jpg` |
| `vr/vr_training_lab.jpg` | faces partly or fully occluded by VR headsets | `Gemini_Generated_VR_1.jpg` |

They are didactic inputs, not WIDER FACE or another labelled benchmark. There are no
ground-truth boxes, so do not use their observed counts to calculate precision,
recall, or average precision.

All depicted people, faces, and personal traits are computer-generated; no real
living person is represented, and any resemblance is coincidental. Google documents
SynthID for Gemini-generated images, and these files are unchanged copies of the
contributor's exports; the watermark has not been independently verified here. The
